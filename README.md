E-Gram Panchayat – AI-Powered Citizen Service Portal

Project Overview

E-Gram Panchayat is a web-based citizen service platform designed to simplify access to Panchayat services through a digital interface.

The application integrates an AI-powered chatbot using Retrieval-Augmented Generation (RAG) and Google Gemini to help citizens find information about available services and application procedures.

Features

Citizen Registration and Login

Birth, Death, Marriage, Income and Caste Certificate Applications

Certificate Application Status Tracking

Professional Tax Management

Online Payment Integration

Payment History

Latest News and Announcements

AI-Powered Citizen Assistance Chatbot

RAG-Based Information Retrieval
